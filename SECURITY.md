# Security Policy

## Supported versions

Only the latest published release and the current `main` branch receive
security fixes.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Use GitHub
Security Advisories for the repository when enabled, or contact the maintainer
privately through <https://github.com/manhvann> with:

- affected version or commit;
- reproduction steps or proof of concept;
- impact and suggested mitigation, if known.

Do not include API keys, tokens, personal data, or production credentials in a
report. We will acknowledge valid reports, investigate, and coordinate a fix
and disclosure timeline with the reporter.
